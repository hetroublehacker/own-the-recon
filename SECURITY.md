# Security policy

## Sensitive reports about this repository

Use GitHub's private vulnerability-reporting feature when it is available. If
it is not available, contact the repository owner privately through a verified
profile channel before disclosing details. Do not place credentials, exploit
details, target data, or unpublished findings in a public issue.

This repository is documentation and validation code; it does not distribute
the listed third-party tools. Report vulnerabilities in a listed tool directly
to that project's documented security contact.

## Findings from an engagement

Report findings only through the target program's authorized channel. A finding
about a tested organization does not belong in this repository's issues,
discussions, pull requests, or Git history.

## Secrets accidentally committed here

Treat the secret as compromised: revoke or rotate it immediately, then contact
the repository owner privately to coordinate history cleanup. Removing a secret
from the latest commit does not remove it from Git history or forks.
